# 数据分析小助手 · 功能清单

> 按模块组织的完整功能面。本清单同时是代码审计/优化的验收基准：每个功能点在改动后必须仍然可用。
> 更新时间：2026-09（nio 分支 · 运营看板（KPI/漏斗/钉卡放映）· 210 测试）。

## 〇、v4.0 定位与变更

**定位**：各行各业通用数据的前置处理工具——导入 → 体检（发现明显问题）→ 一键修复/清洗 → 简单可视化 → 导出给专业软件做深度分析。

**v4.0 移除**（复杂分析交给专业软件）：RFM / 转化漏斗 / 同期群留存 / K-means 聚类 / 帕累托 ABC、统计检验（正态性/组间/卡方/A-B/样本量）、时序预测、同比环比/移动平均、透视表、金融分析全套（收益风险/K线/技术指标/CAPM/组合/ADF）、在线行情（akshare）、HTML 报告、数据集对比。

**v4.0 新增**：数据体检中心（结构化问题清单 + 一键修复）、8 种文本与格式清洗操作。

**v4.1 新增**：IDE 式工作台界面（主区双 tab + 底部工具面板 + 电子表格式交互）。**v4.3 布局微调**：工具分区——清洗/统计/采样/历史移右侧停靠栏（可收起为图标栏），底部只留 SQL 控制台与 Python 变换。

**v4.2 新增**：数据集项目化管理（分组/派生表归组/移动）、多步回溯（版本快照 + 任意步跳转，取代一级撤销）。**v4.4 新增**：体检深化——列间一致性检测（算术关系违反/函数依赖冲突）、格式语义（手机号/邮箱等）、数值粒度、时序缺口、六维质量雷达。

## 二、数据体检中心（核心）

一键体检：纯本地规则引擎（无需 AI），行业无关——只依赖"表格数据长什么样"。

| 输出 | 说明 |
|---|---|
| 质量评分 | 0-100 加权扣分（重复/缺失/结构格式问题/警告），环形图 + 扣分明细 |
| 问题清单 findings | 每条 `{level: error/warn/info, category, column, msg, detail, samples, fix}`；🔴严重→🟡警告→🔵提示排序；上限 80 条（error 优先保留） |
| 一键修复 fix | `{op, params, label}` 指向清洗操作与预填参数，前端点击自动填充清洗面板（用户确认后执行）；**契约：每个 fix 必须能被 cleaning.apply_op 真实执行（有测试保证）** |
| 列画像快洞察 | 数值列（min/max/mean/median/std/偏度/零值/负值/离群）、类别列（唯一值/Top 占比/孤值）、时间趋势（方向/首末变化/最大环比突变）、强相关列对（r≥0.6） |

### 检查规则清单（v4.4 深化后）

| 类别 | 规则 | 修复建议 |
|---|---|---|
| 结构 structure | 完全重复行；空列/Unnamed 列名；列名首尾空白（无冲突时）；常量列；高基数 ID 类列（info）；疑似 ID 列键重复（仅文本列） | drop_duplicates / rename_columns / drop_columns |
| 缺失 missing | 整体缺失率与最差列 Top3；列缺失 >50%；30%~50% 提示 | drop_high_missing |
| 类型 type | 文本列几乎全是数字；混合类型（30%~90% 可转数值）；带格式数字（千分位 `1,234`/货币 `¥100`/百分号 `12%`/单位 `1.5万`/全角 `１２３`）；文本日期列；混合日期格式（多 format 各解析一部分）；**常见格式列识别+违反值（手机号/邮箱/网址/身份证，≥80% 匹配才认定）**；**值长度显著偏离列中位数（截断/拼接风险）** | cast_type / parse_number |
| 文本 text | 首尾空格（含全角空格）；空字符串/纯空白（≠缺失）；全角字符；控制/零宽/乱码字符；连续多余空格 | trim_whitespace / normalize_text |
| 类别 category | 疑似同义标签（仅差空格/大小写/全角，规范化归并检测）；布尔语义取值不统一（true/yes/1/是…） | map_values / unify_boolean_text |
| 数值 numeric | IQR 离群值（>5% 警告）；非负列出现负值（疑似录入错误/哨兵值）；零值占比 >50%；偏度 \|skew\|>2；**小数位精度异常（金额列突现高精度值）**；**量级断裂（与主体差 3 个数量级以上，疑单位混用）** | cap_outliers（盖帽不删行） |
| 日期 datetime | 未来日期（晚于今天，疑似年份错录）；早于 1900 的超远历史；**重复时间戳（近唯一列的同刻多行）**；**时间覆盖缺口（按天粒度缺 >10%，中位间隔 ≤7 天的日级数据才检测，月度/季度不误报）** | 人工确认 |
| **一致性 consistency（v4.4 新增）** | **列间算术关系发现与违反行**（`A×B≈C`/`A+B≈C`/`A−B≈C`，采样匹配率 ≥95% 判定成立，回全量报违反行如 `数量×单价≠金额`；关系成立且无违反时作为正面洞察报告）；**函数依赖冲突**（近似"A 决定 B"但存在同键多值，如订单号→城市/邮编→城市，冲突组 ≤10% 才报） | 无自动修复（不能替用户判断哪列出错），给违反样本供核查 |

**六维质量雷达（v4.4）**：`quality_dims` 输出 完整性/唯一性/一致性/有效性/及时性/结构 各 0-100 分（finding 按 category 归维扣分 + 缺失/重复率打底；无日期列时及时性为 null 前端隐藏该轴），体检卡评分环旁雷达图展示——回答"差在哪一类"而非只有总分。

性能：正则扫描全列向量化；逐值解析（数值/日期）在 ≤2 万采样上执行；算术关系在 ≤5000 采样判定后回全量验证；函数依赖 ≤60 列对 × 1 万采样；百万行秒级。

## 三、清洗与列变换（22 种操作）

- **行级**：去重（可按列）、删缺失行（any/all）、填充缺失（常数/均值/中位数/众数/前向/后向/**线性插值**）、12 种条件筛选（比较/包含/开头/between/isin/空值）、IQR/Z-score 异常值剔除、**异常值盖帽（截断到边界不删行）**
- **文本与格式（v4 新增）**：**去除首尾空格**（含全角/零宽）、**文本规范化**（全角转半角/去控制与乱码字符/压缩连续空白/可选空串→缺失）、**智能数值解析**（千分位/货币/百分号(可选×100)/万·亿单位/全角数字 → 新数值列）、**值映射**（类别标准化，未命中保留或置空）、**按分隔符拆分列**、**布尔语义统一为 是/否**
- **列级**：重命名、删除列、**按缺失率删列/删行**、类型转换（int/float/str/datetime）、分箱（等宽/等频 + 自定义标签）、独热编码（≤30 类）、Z-score/Min-Max 标准化、log(1+x) 变换、日期成分提取（年月日/季度/星期/小时）、正则提取新列
- 兜底：Python 自由变换（先预览后应用，快照重放，30 秒超时）；一级撤销 + 回滚原始 + 操作历史

## 四、快速统计与图表（精简集）

分组聚合（10 种函数）· 相关性（Pearson/Spearman/Kendall 卡片内切换 + 矩阵热力图）· 直方图（2-200 桶）· 箱线图（五数概括）· 频次统计 · describe 汇总 · 时间趋势（D/W/M/Q/Y 重采样）· 异常值检测（IQR/Z-score，只检测不动数据）

辅助可视化：图表推荐（Show Me 思路）、交叉热力、通用表格卡 6 种图表切换（柱/条/折/面积/饼/树图）、缺失值矩阵热力图、重复行明细、两列交互散点（降采样 ≤1000）、AI 自然语言出图。

## 五、SQL 控制台（DuckDB）

数据集注册 `ds1/ds2…` 视图 + 当前集 `df`，**Parquet 视图惰性读取**（不整表载入）；跨数据集 JOIN / 窗口函数；只读两级防护（SELECT/WITH 开头 + 引号感知分号切分）；预览外层 LIMIT 10 万；结果另存新数据集不截断。

## 前端界面结构（v4.2 IDE 式布局）

- **主页（未选数据集）**：居中大虚线拖拽区（点击选择 / 拖文件到窗口任意位置导入，dragover 全窗口高亮）+「📋 粘贴数据」「✨ 生成示例」按钮 +「导入到项目」选择器，无营销页。
- **顶栏**：logo · 📥导入 / 📋粘贴 / ✨示例 · 🩺数据体检 · 🔌MCP（弹窗展示外接地址与复制）· 🌙主题。
- **左数据集栏（v4.2 项目分组）**：按项目分组渲染（📁 分组头：折叠 caret / 名称 / 数量徽标 / hover 出 ✎ 重命名 🗑 删除），「📂 未分组」垫底；「＋ 项目」内联新建；点击分组头设为导入目标（高亮）；派生表条目带 ↳ 溯源标记；顶部搜索框过滤（搜索时空项目自动收起）。
- **工作台 = 左数据集栏 + 主区**：数据集操作条（重命名/项目移动下拉/撤销/回滚原始/体检/图表推荐/导出/删除）→ 主区双 tab「📋 数据表 | 📊 结果(N)」。
  - **数据表（电子表格式只读）**：占满主区；冻结表头 + 行号列；列头含 dtype 与缺失率徽标；**列头点击排序（升↖→降↘→取消三态）**；**列头 ▾ 下拉面板**（按值勾选筛选 Top100+计数 + ∅缺失哨兵、搜索值、该列画像/清洗此列/SQL 预览）；筛选 chips 与「清除全部」；分页 20–500 行/页；`unfiltered_total` 显示筛选后/总数。
  - **结果画布**：体检卡/统计图表卡网格（上限 12 张），体检或分析出结果自动切到该 tab。
- **右侧工具栏（v4.3）**：清洗 / 统计 / 采样 / 历史 四个 tab（344px 停靠栏，» 收起为图标栏，点图标展开并切换）；问题条目 🔧 修复按钮自动预填清洗 tab。
- **底部 SQL/Python 面板**：可拖动分隔条（160px–70vh，双击复位 300px）+ 🗄️ SQL 控制台 / 🐍 Python 变换 两个 tab + 整体折叠成一行。
- **🕘 历史面板（v4.2 多步回溯）**：时间线每条数据操作带「⏪ 回到这步」按钮；当前版本标「● 当前」；跳转记录标「跳转」；未来分支条目淡显仍可跳回；快照被淘汰的条目标「快照已清理」禁用。
- **状态栏**（v4.1）：当前数据集行列/缺失率/列型/结果卡数/数据不出本机/版本号。
- 明暗双主题；应用内 AI 对话界面已移除（后端能力保留，经 🔌 MCP 外接）。
