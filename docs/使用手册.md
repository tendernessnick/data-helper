# 📊 数据分析小助手 · 使用手册

> 面向普通用户的使用说明（v4.4）。这是一款**本地运行**的数据预处理工具：导入 → 🩺 体检 → 🔧 修复/清洗 → 简单统计 → 导出，把干净数据交给你的主力分析软件（Excel / SPSS / Python / BI 等）。
>
> **数据全程不出本机**：所有检查、清洗、统计都在你电脑上完成；即使开启 AI 功能，也只发送列名、类型、统计量等结构摘要，原始数据永不离开本机。

## 1. 启动与数据存放

| 方式 | 步骤 |
|---|---|
| **exe（推荐普通用户）** | 双击 `数据分析小助手.exe` → 自动打开浏览器进入应用。关闭浏览器标签页后，再次双击 exe 即可重新打开。 |
| **源码（开发者）** | `python run_app.py`（自动挑空闲端口并开浏览器），或 `uvicorn backend.app.main:app --port 8765`。 |

- 数据保存在**程序同目录的 `data/` 文件夹**（exe 版与源码版数据互相独立）。
- 每次启动会随机挑选空闲端口，地址以启动窗口显示的为准。
- 状态栏常驻「数据不出本机」提示。

## 2. 界面导览

进入某个数据集后，界面分为五个区域：

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：导入文件 / 粘贴数据 / 示例数据 / 🔌MCP / 🌙主题        │
├──────────┬──────────────────────────────────┬──────────────┤
│ 左栏      │  主区（📋 数据表 / 📊 结果）      │ 右侧工具栏    │
│ 数据集    │  数据集操作条（重命名/撤销/体检…） │ 🧹清洗        │
│ (按项目   │  电子表格 + 分页                  │ 📈统计        │
│  分组)    │                                  │ 🎯采样        │
│          ├──────────────────────────────────┤ 🕘历史        │
│          │ 底部：🗄️SQL 控制台 / 🐍Python 变换 │ (»可收起)     │
├──────────┴──────────────────────────────────┴──────────────┤
│ 状态栏：行列数 / 缺失率 / 列型统计 / 卡片数 / 数据不出本机    │
└────────────────────────────────────────────────────────────┘
```

- **左栏**：数据集列表，按项目分组；顶部搜索框可按名称过滤。
- **主区**：两个标签页。「📋 数据表」浏览原始数据；「📊 结果」存放体检报告和统计图表卡片（上限 12 张，超出自动淘汰最早的）。
- **右侧工具栏**：清洗 / 统计 / 采样 / 历史四个面板；点右上角 » 收起成一列图标，再点图标展开。
- **底部面板**：SQL 控制台与 Python 变换；中间分隔条可上下拖动调节高度（双击复位），也可整体折叠。
- **主题**：顶栏 🌙 按钮切换明 / 暗色，图表颜色自适应。

## 3. 五分钟上手流程

1. 顶栏点「✨ 示例数据」→ 生成一份 370 行、自带缺失和重复的销售数据，并自动进入工作台。
2. 数据集操作条点「🩺 数据体检」→ 自动切到「📊 结果」页，看评分、雷达图和问题清单。
3. 点问题条目旁的「🔧 修复」→ 右侧清洗面板自动填好参数 → 确认后点「执行（可撤销）」。
4. 再跑一次体检，对比评分变化。
5. 操作条点「导出CSV」，拿到干净数据。

## 4. 导入数据

| 入口 | 用法 |
|---|---|
| 📥 导入文件 | 支持 CSV / XLSX / JSON / TXT。自动识别中文编码（UTF-8 / GBK）和分隔符；Excel 多工作表会以标签形式出现在操作条，可一键各存为数据集。 |
| 📋 粘贴数据 | 在 Excel 里复制区域 → 点「粘贴数据」→ 直接 Ctrl+V（Tab 分隔自动处理）→ 确认列名后导入。 |
| ✨ 示例数据 | 内置 370 行含缺失/重复的销售数据，用于体验流程。 |
| 拖拽 | 把文件直接拖到应用窗口任意位置即可上传。 |

**大文件**：超过 16MB 的 CSV 自动走流式导入（分块处理，不会撑爆内存），上传上限默认 500MB。百万行级数据是这个工具的主战场。

**导入到项目**：主页拖拽区 / 导入时有「导入到项目」选择器，选好项目后新数据集直接归组（详见下一节）。

## 5. 项目化管理数据集

数据多了以后，用项目把相关的表放在一起：

- **新建项目**：左栏顶部「＋ 项目」，输入名称回车。
- **归组**：导入时选目标项目；也可以随时在数据集操作条的项目下拉里切换归属。
- **派生表自动归组**：对某张表做采样、SQL 存为新数据集、导入 Excel 工作表，生成的派生表**自动留在源表所在项目**，名字旁带 **↳** 溯源标记（鼠标悬停可见来源）。
- **分组操作**：分组头可折叠 / 展开；悬停出现 ✎ 重命名、🗑 删除（删除项目不会删数据，成员移回「📂 未分组」）。
- **点击某个分组头** = 把它设为当前导入目标（高亮），之后导入的文件默认进这个项目。
- 顶部搜索框按名称过滤数据集（搜索时空项目自动收起）。

## 6. 数据表：浏览、排序、筛选

数据表是电子表格式只读视图，列头带类型徽标（text / int / float / datetime）和缺失率（∅n%）。

| 操作 | 方法 |
|---|---|
| 排序 | 点列头：升序 ↖ → 降序 ↘ → 取消，三态循环 |
| 按值筛选 | 点列头 ▾ 打开面板：勾选值（Top 100 + 计数），**∅缺失**作为特殊选项单独列出；面板内可搜索值 |
| 更多列操作 | 同一 ▾ 面板里还有：该列画像、清洗此列（自动跳清洗面板）、SQL 预览 |
| 清除筛选 | 主区 tab 右侧出现筛选 chips，单个 ✕ 或「清除全部」；也可用分页区的「↺ 重置视图」 |
| 分页 | 底部上一页 / 下一页，每页行数可切换（20–200） |

筛选和排序只影响**视图**，不改数据本体；要真正删除/保留行，请用清洗面板的「按条件筛选行」。

## 7. 数据体检（核心功能）

数据集操作条点「🩺 数据体检」，自动切到结果页生成体检报告卡。

**报告包含**：

- **质量评分**（0–100）：环形图 + 扣分明细，一眼看整体。
- **六维质量雷达**：完整性 / 唯一性 / 一致性 / 有效性 / 及时性 / 结构 各 0–100 分，回答"差在哪一类"。没有日期列时不显示及时性轴。
- **概览指标**：行数 / 列数 / 重复行 / 缺失占比 / 内存。
- **问题清单**：按严重度排序，🔴 严重 → 🟡 警告 → 🔵 提示；每条带证据样本。
- **下钻**：缺失矩阵热力图、重复行明细等深度查看入口。

**检查覆盖**（纯本地规则，行业无关）：

| 类别 | 典型发现 |
|---|---|
| 结构 | 完全重复行、空列、常量列、ID 列键重复 |
| 缺失 | 整体/列级缺失率、高缺失列 |
| 类型 | 文本数字（`1,234`、`¥100`、`12%`、`1.5万`、全角数字）、混合类型、文本日期、手机号/邮箱/网址/身份证格式违反值 |
| 文本 | 首尾空格、全角字符、乱码/零宽字符、连续空格 |
| 类别 | 同义标签（"北京"vs"北京 "）、布尔取值不统一（yes/是/1 混用） |
| 数值 | 离群值、不该为负的负值、高零占比、小数位突增、量级断裂（疑单位混用） |
| 日期 | 未来日期、超远历史、重复时间戳、按天数据的时间缺口 |
| 列间一致性 | **算术关系违反**（如 数量×单价≠销售额，给出违反行样本）；**函数依赖冲突**（同一订单号对应两个客户） |

**一键修复**：可自动处理的问题条目带「🔧」按钮，点击自动把清洗面板填好参数，你确认后执行。注意：**体检是建议不是判决**——重复行、离群值在某些业务里是正常的（如零售同单同品多行），修复前请结合业务确认。算术关系、函数依赖这类"哪列才是错的"无法替你判断的问题，只给样本供核查，不提供自动修复。

## 8. 清洗与列变换（22 种操作）

右侧「🧹 清洗」面板：选操作 → 填参数 →「执行（可撤销）」。结果生成新版本（见第 11 节），随时可退。

| 分组 | 操作 | 要点 |
|---|---|---|
| 行级 | 删除重复行 | 可指定按哪几列判重，留空=整行 |
| | 删除含缺失值的行 | 任一列空即删 / 全部列空才删 |
| | 填充缺失值 | 常数 / 均值 / 中位数 / 众数 / 前值 / 后值 / 线性插值（适合时序） |
| | 按条件筛选行 | 12 种条件：等于/不等于/大于/大于等于/小于/小于等于/包含/开头是/介于/属于列表/为空/不为空 |
| | 剔除异常值行 | IQR 或 Z-score |
| | 异常值盖帽 | 截断到边界值，**不删行** |
| 文本与格式 | 去除首尾空格 | 含全角空格、零宽字符 |
| | 文本规范化 | 全角转半角、去控制/乱码字符、压缩连续空格 |
| | 智能数值解析 | `1,234` / `¥100` / `12%` / `1.5万` / 全角数字 → 数值列 |
| | 值映射 | 类别标准化（如"北京/北京市"→"北京"），体检会预填建议映射 |
| | 按分隔符拆分列 | 一列拆多列 |
| | 布尔语义统一 | true/yes/1/是… 统一成 是/否 |
| 列级 | 重命名列 | 在表格里直接改各列名 |
| | 删除列 / 按缺失率删列 | 也可按缺失率删行 |
| | 转换列类型 | 整数 / 小数 / 文本 / 日期时间 |
| | 分箱 | 等宽 / 等频，可自定义标签（如 低/中/高） |
| | 独热编码 | 类别列转 0/1 列（≤30 类） |
| | 标准化 / 归一化 | Z-score 或 Min-Max |
| | 对数变换 | log(1+x) |
| | 提取日期成分 | 年 / 月 / 日 / 季度 / 星期 / 小时 |
| | 正则提取新列 | 用正则从文本列抽出新列 |

## 9. 统计分析与图表

右侧「📈 统计」面板：选分析类型 → 配置 →「开始分析 → 结果页」。

| 分析类型 | 说明 |
|---|---|
| 分组聚合 | 按类别列分组，对数值列求和 / 均值等（10 种函数），可加多个指标 |
| 相关性分析 | Pearson / Spearman / Kendall，矩阵热力图，卡片内可切换方法 |
| 分布直方图 | 数值列分布，2–60 桶可调 |
| 箱线图 | 五数概括 + 离群点 |
| 频次统计 | 类别列 Top N 计数 |
| 汇总统计 | describe：count / mean / std / min / 四分位 / max |
| 时间趋势 | 按天 / 周 / 月 / 季 / 年重采样聚合 |
| 异常值检测 | 只标出异常，不动数据；要处理去清洗面板 |

结果以卡片形式进入「📊 结果」页，通用表格卡可切换 6 种图表（柱 / 条 / 折线 / 面积 / 饼 / 树图）并导出。不知道画什么图时，点操作条「📊 图表推荐」，工具按列类型自动推荐。

## 10. 采样

右侧「🎯 采样」面板，三种方式，结果**另存为新数据集**（原表不动）：

- **随机采样**：抽 N 行。
- **分层采样**：按某类别列分层，每组抽 N 行。
- **前 N 行**：直接取前 N 行。

千万行级大表建议先采样出小表再工作量较小的清洗方案，思路验证后再回大表执行。

## 11. 历史与多步回溯（做错了怎么办）

**每次清洗 / 变换前都会自动保存版本快照**，所以任何操作都可以反悔：

| 操作 | 入口 | 效果 |
|---|---|---|
| 撤销上一步 | 操作条「↩ 撤销」 | 连续多级撤销，一路退回 |
| 回到任意一步 | 右侧「🕘 历史」面板，每条记录旁「⏪ 回到这步」 | 直接跳到那个版本 |
| 回滚原始 | 操作条「⏮ 回溯原始」 | 秒回最初上传的 v0 |

- **跳错了可以再跳回来**：跳转到历史版本后，后面的记录不会丢（淡显为"未来分支"），随时再跳回去；只有当你基于跳转后的版本**做了新操作**，未走的分支才会被丢弃。
- 「回溯原始」是把 v0 的数据落成一个新版本，本身也可撤销。
- 快照最多保留 **20 份**，超出自动淘汰最旧的；被淘汰的条目在历史面板标「快照已清理」不可跳转。
- 重命名、删除数据集等管理操作不受影响；删除数据集会连同其历史一起删除。

## 12. SQL 控制台

底部「🗄️ SQL 控制台」，基于 DuckDB：

- 数据集自动注册为 `ds1`、`ds2`…，当前选中的数据集还可以用 `df`。
- 支持跨表 JOIN、窗口函数等标准 SQL；大表惰性读取，不整表载入。
- **只读**：仅允许 SELECT / WITH 开头的查询，不能改数据。
- 「▶ 运行」看结果；「💾 存为数据集」把查询结果存成新数据集（不截断，自动归入当前项目）。

```
SELECT 地区, SUM(销售额) AS total
FROM df
GROUP BY 地区
ORDER BY total DESC
```

## 13. Python 变换

底部「🐍 Python 变换」，适合清洗面板覆盖不到的自定义逻辑：

- 直接用 `df`（当前数据）、`pd`、`np` 写 pandas 代码；执行后 `df` 即新数据。
- **先「▶ 预览运行」看结果，再「✔ 应用」生效**；卡片上也可再次应用。
- 代码模板下拉提供常用片段（新增列、筛选、缺失处理等）。
- 30 秒超时保护；应用前自动存版本快照，可撤销。

## 15. 运营看板（钉卡 / KPI / 漏斗 / 放映）

主区第三个标签「📌 看板」，把常用分析固化成一块日常看板：

- **钉卡**：在「📊 结果」页，每张分析卡片右上角有「📌 钉看板」按钮（体检报告、KPI、漏斗、各类统计图都可钉）。钉选会**保存在本机**，刷新或重启软件后看板自动重建；数据更新后重进看板即展示最新值。
- **KPI 指标卡**：右侧「📈 统计」→ 分析类型选「KPI 指标」→ 选指标列和聚合方式（求和/平均/行数）；再选一个日期列即可附带**环比**（▲红涨▼绿跌 + 上期值 + 口径说明，如"近300天 vs 前300天"）。
- **转化漏斗**：分析类型选「漏斗分析」。事件日志数据（一列存步骤名）用"单列步骤"模式，按顺序填步骤（如 `浏览,加购,下单,支付`），可选按用户列去重；宽表数据（每步一列）用"多列标记"模式。结果为漏斗图 + 逐步转化率。
- **放映模式**：看板页右上角「🖥 放映」隐藏所有侧栏全屏展示，适合投屏汇报，按 **Esc** 退出。

## 16. AI 与 MCP 外接（可选）

本工具支持接入大模型做对话式分析，且**你的 API Key 与数据分离**：LLM 在云端客户端，数据留在本机，只传输列结构摘要。

1. 顶栏点「🔌 MCP」→ 复制弹窗里的 MCP 地址。
2. 在 Cherry Studio / ChatWise 等支持 MCP 的聊天客户端里，配置你自己的 API Key，把该地址添加为工具源。
3. 之后可在客户端里对话式完成：数据集浏览、体检、SQL 查询、分组统计、相关分析、趋势等（10 个只读工具，结果 200 行封顶）。

详细步骤见 [docs/MCP.md](MCP.md)。

## 17. 常见问题 FAQ

**Q：我的数据安全吗？会上传吗？**
体检、清洗、统计、SQL、Python 全部在本机执行。只有当你主动配置 AI/MCP 时，才会把**列名、类型、统计量**等结构摘要发给所配置的大模型服务，原始行数据不出本机。

**Q：数据保存在哪里？**
程序同目录的 `data/` 文件夹（Parquet 格式 + 原始上传文件 + 版本快照）。备份这个文件夹=备份全部数据。exe 版和源码版的 `data/` 互相独立。

**Q：误删了列 / 清洗错了怎么办？**
「↩ 撤销」连续回退；或到「🕘 历史」面板任意跳步；最坏情况「⏮ 回溯原始」回到上传时的样子。见第 11 节。

**Q：体检说有问题，但业务上这是正常的？**
体检是**基于通用规则的提示**，不是判决。例如零售数据同一订单同一商品多行是正常明细；负数可能是退货。请结合业务判断，只修复确认的问题。

**Q：多大数据量合适？**
百万行是主战场（体检秒级）。千万行级取决于列数与内存，建议先用采样表验证思路。上传上限默认 500MB（可用环境变量 `DATA_HELPER_MAX_UPLOAD_MB` 调整）。

**Q：SQL 为什么不能 UPDATE / DELETE？**
SQL 控制台定位是**查询与派生**（只读防护）。要改数据请用清洗面板或 Python 变换，它们都带版本快照，更安全。

**Q：Excel 有多个工作表怎么办？**
正常导入 xlsx 后，其他工作表会以标签形式出现在数据集操作条，点一下即存为独立数据集，并自动归入源表的项目。

**Q：结果卡片有上限吗？**
「📊 结果」页最多 12 张卡片，超出自动移除最早的；卡片可手动关闭。

**Q：端口被占用 / 启动失败？**
程序每次启动自动挑选空闲端口，以启动窗口打印的地址为准。若浏览器没自动打开，手动访问窗口里显示的 `http://127.0.0.1:端口`。
