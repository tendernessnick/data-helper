# 百万行真实电商数据集端到端分析

> 用「数据分析小助手」对 **UCI Online Retail II**（1,067,371 行真实在线零售交易，2019 年发布，CC BY 4.0）完成的一次完整业务分析：从原始 CSV 上传、清洗、客户分层、留存、聚类到运营建议。所有结论均由本工具的后端真实计算产出，原始结果 JSON 见 [results/](results/)。

## 业务背景与问题

某英国在线礼品零售商（B2B + B2C 混合），两。年间的全部发票级交易流水。管理层想知道：

1. **客户价值结构**：谁是最有价值的客户？头部客户集中度有多高？
2. **流失风险**：哪些高价值客户正在流失？
3. **新客质量**：新客首月留存如何？哪个获客渠道月份的客户质量最好？
4. **退货**：退货损失有多大、集中在哪些市场？

## 数据与口径

| 项 | 值 |
|---|---|
| 原始数据 | 1,067,371 行 × 8 列（92MB CSV，流式上传直写 Parquet，2.6s） |
| 时间范围 | 2009-12-01 ~ 2011-12-09（两个财年 sheet 合并） |
| 有效销售 | 805,549 行（剔除取消单 `InvoiceNo` 前缀 C、退货行 `Quantity<0`、无客户 ID 散单、`Price<=0`） |
| 有效客户 | 5,878（有消费行为且可识别 ID） |
| 销售额 / 订单 | £17,743,429 / 36,969 张发票，**客单价 £479.95** |
| 退货 | £1,095,100（占全部明细行 2.27%） |

清洗用 SQL 控制台一步完成（只读防护内，DuckDB 直读 Parquet 视图）：

```sql
SELECT "InvoiceNo", "CustomerID", "InvoiceDate", "Quantity", "Price", "Country",
       ROUND("Quantity" * "Price", 2) AS "Amount"
FROM ds1
WHERE "CustomerID" IS NOT NULL AND "Quantity" > 0
  AND "InvoiceNo" NOT LIKE 'C%' AND "Price" > 0
```

## 一、RFM 客户分层：41% 的客户贡献 82% 的收入

工具：`业务模板 → RFM`（五分位打分 R/F/M → 8 层）。

| 分层 | 客户数 | 金额 (£) | 金额占比 |
|---|---:|---:|---:|
| 重要价值客户 | 2,425 | 14,563,629 | **82.08%** |
| 重要挽留客户 | 660 | 1,461,392 | 8.24% |
| 重要发展客户 | 237 | 591,587 | 3.33% |
| 一般客户 | 1,235 | 317,881 | 1.79% |
| 重要挽留(剩余各层合计) | 861 | 808,940 | 4.56% |

交叉验证：按客户金额十等分，**头部 10% 客户贡献 63.9% 的金额**——典型的 B2B 重尾部结构。

## 二、复购与 LTV：中位 LTV £899，均值 £3,019

工具：`SQL 控制台`。

- **复购率 72.39%**（4,255 / 5,878 客户有两张以上发票）——批发属性带来的高复购；
- 平均 LTV £3,018.62，**中位数只有 £898.92**——长尾客户拉低中位数，均值被大客户抬高 3.4 倍，做客户预算分配必须分群而不能用均值；
- 最高单客 LTV £608,822。

## 三、同期群留存：新客次月留存 16%~25%

工具：`业务模板 → 同期群留存`（按首购月分 12 个群，月粒度）。

- 12 个同期群的 **M1 留存率在 16.1%~25.5%** 之间波动；
- 2011-04 群 M1 留存 25.5%、其后各期稳定在 18%~26%，是两年内质量最好的获客月份；
- 留存曲线呈"断崖后走平"形态：M1 跌到 ~20% 后长期能维持 11%~25%，说明留下的客户有很强的批发黏性。

## 四、客户生命周期漏斗：首购 → 复购 → 高价值

工具：`SQL` 从交易流水派生用户级事件表，`业务模板 → 转化漏斗`（到达制口径）：

| 步骤 | 到达人数 | 单步转化 | 整体转化 | 较上步流失 |
|---|---:|---:|---:|---:|
| 首购 | 5,878 | — | 100% | — |
| 复购(≥2 张发票) | 4,255 | 72.39% | 72.39% | 1,623 |
| 高价值(金额≥P75) | 1,458 | 34.27% | **24.80%** | 2,797 |

业务含义：真正的瓶颈不在"复购"（72% 已相当高），而在**复购客户向高价值的跃迁**——34% 的复购客户能爬到价值头部，运营应聚焦这一段的手段（品类扩展、批发门槛权益）而非泛泛促活。

## 五、K-means 聚类 × RFM：算法分群与规则分层互相印证

工具：`SQL` 生成客户级 R/F/M 原始值 → `业务模板 → K-means`（k-means++ 初始化、多次重启、肘部法 + 轮廓系数自动选 k）。

- **自动选 k=2**（轮廓系数 0.923）：结构被批发/零售的巨大金额差异主导——这一结论本身就是重要发现（数据里存在两种客户物种）；
- **强制 k=4** 后出现可运营的四类（轮廓系数 0.593）：

| 簇 | 样本数 | 占比 | R 均值(天) | F 均值(次) | M 均值(£) | 解读 |
|---|---:|---:|---:|---:|---:|---|
| 簇3 鲸鱼客户 | 19 | 0.4% | 26.6 | 128.8 | 140,291 | 顶级批发商，专属客户成功 |
| 簇2 高频批发 | 263 | 5.3% | 30.3 | 32.7 | 17,048 | 活跃大客户，锁定长期协议 |
| 簇1 稳定大众 | 3,057 | 61.1% | 73.1 | 5.5 | 2,048 | 价值主力，提升频次 |
| 簇4 流失客户 | 1,661 | 33.2% | **467.2** | 2.1 | 750 | 一年以上未购买，需唤醒 |

与 RFM 对照：RFM 的"重要挽留客户"（660 人，金额 £1.46M、占比 8.24%）与聚类的簇4 高度呼应——**两种方法独立得出同一批流失风险人群，结论可信**。规则分层给出可解释的运营动作，算法分群给出无监督的客观结构，互为校验。

## 六、退货与地理：UK 占 83% 收入，退货 £1.10M

工具：`SQL 控制台`（含退货全额口径 `Quantity<0` 或取消单）。

| 国家 | 订单数 | 销售额 (£) | 退货额 (£) |
|---|---:|---:|---:|
| United Kingdom | 40,505 | 14,723,148 | 916,724 |
| EIRE | 727 | 621,631 | 43,129 |
| Netherlands | 250 | 554,232 | 5,707 |
| Germany | 1,095 | 431,262 | 13,274 |
| France | 738 | 355,257 | 28,753 |

- UK 一家独大（83.0%），但 **Netherlands 户均价值异常突出**：250 张订单做了 £554K（单均 £2,217，是整体客单价的 4.6 倍）——典型批发市场，值得设本地仓/专属客服；
- France 退货率相对销售额偏高（£28.8K / £355K ≈ 8.1%），需排查商品目录与尺码类目。

## 运营建议（基于以上量化结论）

1. **防流失优先**：锁定 RFM"重要挽留"∩ 聚类"簇4"的约 1,600 名一年未购客户（其中 660 人曾贡献 8.2% 金额），用 90 天唤醒礼包 + 批发折扣挽回 10% 即可增收约 £15 万/年；
2. **抓复购→高价值跃迁**：4,255 个复购客户中 2,797 人未达 P75，针对其首购品类做关联推荐，把跃迁率从 34% 提高 5 个百分点 ≈ 全域金额 +3~4%；
3. **批发通道单独运营**：k=2 聚类证实数据存在"零售/批发"双结构，建议对 F≥20 的 282 个批发账户（簇2+簇3）设最低起订量与季度返利；
4. **欧洲市场复制荷兰模式**：Netherlands 单均 £2,217 验证了西欧批发需求，优先在 Germany/France 试点本地批发目录。
